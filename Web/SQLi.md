# SQLi
## 1. What is SQLi (SQL Injection)?
`SQL injection`은 공격자가 어플리케이션의 `데이터베이스 쿼리`에 `간섭`할 수 있게 하는 보안 결함 임. 공격자는 다른 사용자의 정보나 어플리케이션에서 사용할 수 있는 모든 데이터를 비롯해 접근 권한이 없는 데이터를 `조회`, `수정` 또는 `삭제` 가능. 이러한 행위는 어플리케이션의 기능이나 콘텐츠를 영구적으로 변경하거나, 서버를 침해하거나, 서비스 거부를 일으킬 수 있음.

예를들어 웹사이트가 아래와 같이 동작 한다고 할 때
- 사용자가 로그인, 검색, 상품 보기 같은 행동을 함
- 웹사이트가 그 정보를 데이터베이스에 물어봄
- 데이터베이스가 답을 주면 화면에 보여줌

이때 웹사이트가 사용자가 입력한 내용을 `제대로 확인하지 않고` 그대로 데이터베이스에 넘기면 문제가 생김.

비유:
식당에서 손님이 주문지에 
"김치찌개 하나"라고 적어야 하는데
"김치찌개 하나, 주방 금고 비밀번호, 매출 전표" 라고 적음
그런데 주방장이 주문지를 `확인도 안 하고` 그대로 실행해 버리는 상황.

로그인 예시:
```
SELECT * FROM users WHERE username = 'usernameInput' AND password = 'passwordInput'
```
